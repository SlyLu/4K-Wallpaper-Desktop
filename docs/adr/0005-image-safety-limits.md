# ADR 0005: V1 图片解码安全上限

- 状态：已接受
- 日期：2026-08-20

## 背景

壁纸可能来自在线 Provider 或用户目录。仅检查扩展名和文件头无法阻止损坏图片、格式伪装或解压缩炸弹消耗过量内存。REQUIREMENTS.md 要求写库和设置壁纸前尝试读取并确认图片有效，但未给出具体上限。

## 决策

- 输入文件最大 256 MiB。
- 单边最大 16384 像素。
- 总像素最大 100,000,000。
- 解码器累计分配上限 512 MiB。
- 仅启用 JPEG、PNG、WebP、BMP；格式以二进制内容识别结果为准。
- 所有在线下载和本地设置入口都执行完整受限解码。

这些限制覆盖 V1 明确要求测试的 8K（7680×4320）壁纸，同时为异常输入提供可恢复的 `AppError::Image`。

## 影响

超过安全上限的超高分辨率素材会被拒绝，即使解码器理论上支持。未来调整上限只修改 Image Core 策略，不影响 Provider、数据库或平台接口。
