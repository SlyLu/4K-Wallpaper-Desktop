# ADR 0004: V1 图片适配模式语义

- 状态：已接受
- 日期：2026-08-20

## 背景

REQUIREMENTS.md 明确定义 Fill 为等比覆盖和居中裁剪，但未明确 Fit 与 Center 的空白区域颜色，也未明确 Center 是否允许放大。

## 决策

- `Fill`：等比缩放至覆盖目标，居中裁剪。
- `Fit`：等比缩放至完整包含在目标内，剩余区域使用黑色。
- `Center`：保持原始像素尺寸，不缩放；超出目标时居中裁剪，小于目标时居中放置，剩余区域使用黑色。
- `Stretch`：忽略原比例，精确缩放到目标尺寸。
- 所有处理结果使用 JPEG 写入 `cache/processed/`，原图不修改。

## 影响

四种模式在 Windows 和 macOS 使用同一 Rust Core 算法，不受系统原生壁纸填充策略差异影响。未来如增加背景颜色配置，只扩展处理参数，不改变平台壁纸接口。
